Entry for the make.fun bounty [Warning Label for Humans: One Line, Big Laugh](https://make.fun/bounty/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85).

The program writes one single-line safety warning label that should come printed on every human being to `/output/entry.txt` — 160 characters or fewer, funny first and plausible second.

## The line

> WARNING: This human says "I'm five minutes away" and is still at home.

## Run

```sh
python3 main.py
```

Requires Python 3.13 (the competition runtime). No dependencies, no network.
